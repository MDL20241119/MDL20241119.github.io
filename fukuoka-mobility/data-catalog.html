DATA STATUS / 評価基準とデータの性質

曖昧な総合点は付けません。以下の5項目を独立して記載し、裏付けのない点数・精度・最新性は「未確認」と表示します。

FRESHNESS / 最新性

基準日、配信の有効期間、取得日を別々に記録します。原典と現況の一致を確認した記録がなければ「現況との一致は未確認」です。

COVERAGE / 網羅性

収録対象、地域、抜粋範囲を明記。レコードが存在しても、地域の全交通・全施設を収録したとは扱いません。

POSITION / 位置精度

報告座標・概略位置・区域単位を区別。座標があっても、誤差の実測や入口確認がなければ精度を点数化しません。

LICENSE / 利用条件

元ファイルにライセンスと条件へのリンクがある場合は「記載あり」。第三者の権利や別手続を含む包括的な適法性の保証ではありません。

ANALYSIS READY / 分析可能性

具体的な用途に接続済みか、条件付きかを表示。単にダウンロードできることとは区別します。

OPEN / VERIFIED / PARTNER

OPENはオープンな利用条件を記録したデータ。VERIFIEDはMDLによる内容・運行条件等の確認記録、PARTNERは提供合意があるものだけ。現在、その確認記録がない情報をいずれにも昇格させていません。

USED：分析・表示に利用中 / PARTIAL：一部利用 / AVAILABLE：利用可能・未実装 / PLANNED：今後の候補 / UNKNOWN：要確認

公共機関のWebで読める情報も、利用条件を確認できなければOPENとは表示しません。
