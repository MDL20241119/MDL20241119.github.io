# MDL 大分県イベントカレンダー

公開先：https://mobilitydlab.com/oita-events/

モビリティデザインラボ公式HPの特設ページ。2026年9月〜2027年2月の28日程と、日程未確定8案件を掲載。受付・本大会・関連講演は別日程として数える。

## 内容と更新

- `events.js`：日程、県の関与、主催者・窓口、公式情報URL、未確定案件。
- `app.js`：分類・県の関与・11月1日以降の絞り込み。日程未確定案件に日付条件は適用しない。
- `index.html`：初期状態の全件表示をHTMLにも収録。データを更新したら、初期HTMLも同じ内容に更新する。
- `styles.css`：スマートフォン対応の誌面風デザイン。
- `photos.js`、`assets/`：写真の出典・加工内容・ライセンス、画像とフォント。

整理基準日：2026年9月11日。提供された調査一覧と県・主催者・県立施設等の一次情報に基づく。各カードの公式情報リンクを優先して最新状況を確認する。

## 県の関与を表示する基準

正式な主催・共催・協賛・後援の表記と、県事業・委託・実行委員会参画・補助・県立施設・県公式掲載・直接関与未確認を分ける。共同主催を正式な「共催」と読み替えない。県公式サイトへの掲載だけでは、主催や支援を推定しない。県立施設と県本体の主催を混同しない。複数の役割は併記する。

仕様書や募集資料の予定日、一般向けに公表された日程、日程未公表・延期を区別。契約期限や認定日を開催日とみなさない。掲載は車両の出展・運行承認を示さない。

県名義の共催・協賛を確定できた案件は今回の一覧では0件。絞り込み項目は今後の確認結果を収録できるよう残している。

## 写真・公開

写真は会場・地域・過去の活動・テーマの参考イメージ。将来の開催風景とは扱わない。写真ごとの権利表記はページ末尾と `photos.js` を参照。フォントのOFLは `assets/fonts/` に収録。MDLの画像・文章を含む全体への一括した再利用ライセンスは付与しない。

このディレクトリはビルド不要の静的サイト。GitHub Pagesのmainブランチ・ルート公開により配信する。トップページのNEWSから `oita-events/` へリンク。外部の動的データ取得・計測・フォームは使わない。
