# e-Palette ONE UI/UX 更新

更新日：2026-09-26。合成データを用いた機能検証版。実車運用・決済・外部接続は未実施。

## 画面設計

- ネイビー・白・青の一貫した配色。重要な行動と期限を最上段に表示し、故障・欠測は通常の充電案より優先。
- 今日：必要な対応、3台の準備状況、よく使う仕事、時刻順の予定、引継ぎ。完了した予定は折りたたむ。
- 予定：小さい横スクロールの時間表を、日付・車両フィルター付きの時刻順一覧へ置換。
- 車両：残量、測定時刻、状態の意味、次の予定、状態確認、異常報告を車両単位に整理。
- その他：業務操作と検証用操作を分離。認証が必要な保存用管理画面は任意の入口から開く。
- 充電：AC/DCの所要時間を上下限とも保持。現在地の出発期限を表示。既に依頼があれば重ねて依頼せず、担当者の受領確認へ誘導。
- 乗車予約：初期条件の候補を自動表示 → 便を選択 → 内容を明示確認 → 確定。取消は別の明示確認。連携規格の説明は折りたたむ。

## 操作とアクセシビリティ

主ボタンは原則64 CSS px。本文は18pxを基準に、補助情報は16px前後。文字拡大ボタンで125%へ切替。モバイルの常設メニューは「今日・予定・車両・その他」の4つ。状態は文字・アイコン・色で表現。フォーカス輪郭、本文へのスキップ、Radixのフォーカストラップ・Escape対応を維持。

定型予定は既定条件なら2操作、推奨充電依頼はホームから2操作。初期候補表示後の乗車予約は選択・確定の2操作。日時や人数を変更する操作は別。点検、体調、忘れ物・固定などの安全確認は個別に残す。最小タップ数は安全確認の削減を意味しない。

## ログイン不要とデータ保護

| 入口 | 保存先・権限 |
|---|---|
| `/`、`/connections`、`/try/approvals/*` | 各タブ内のsessionStorage。合成データのみ。サーバーAPIに送らない。|
| `/workspace`、`/workspace/connections` | 本人認証を要求。所有者別D1ワークスペース。|
| `/approvals/*`、業務API、CSV、GTFS | 認証・本人・役割・委任スコープをサーバー側で確認。|

匿名の共通ユーザーを作成しない。ゲスト予約は認証済み台帳へ移行しない。ローカル承認はサーバー承認として使えない。保存できない場合は警告し、予約ページへの遷移で保存できていない確定案を進めない。開発環境の認証フォールバックを削除。サイト入口を公開しても、保存済み利用者情報は公開しない。

## 検証

自動試験：既存56件（domain 22・SQLite 4・integration 30）と、ゲスト・表示判定・境界12件、計68件。改変・期限切れ・状態更新後の承認拒否、再確定による二重計上防止、取消前の未変更、充電依頼後の表示、安全確認を自動完了にしないこと等を確認。

ブラウザー：管理されたローカルプレビューで、初回ログイン不要、ホーム、充電依頼後の受領待ち表示、候補表示から予約・取消の確認画面、各画面のモバイル表示を確認。390px/320px幅のiframe（スクロールバーを除く本文幅375px/305px）で横はみ出しなし。390pxで文字125%に拡大し、4画面の表示を確認。これは実機・高齢者テストやWCAG全項目の適合判定ではない。

匿名APIの直接ナビゲーションは検証ブラウザー側でブロックされたため、HTTP応答の実測済みとは記録しない。認証フォールバック不在はソース試験、既存の所有者・役割・承認条件は自動試験で確認した。本番での匿名HTTP応答・実組織権限は別途検証が必要。
