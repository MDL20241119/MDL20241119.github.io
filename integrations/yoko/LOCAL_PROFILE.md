# 採用範囲と外部依存

確認日：2026-09-21。これはローカル試験の範囲です。運用中の交通サービスへの接続確認、認定、全面適合を表しません。

| 層 | このコードで確認できる範囲 | 残る範囲 |
|---|---|---|
| 共通 Core | 役割・所有者・事業者の境界、本人確認済み操作、状態遷移、定員、再送、取引と履歴の一体性 | 実運行データ、監視と運用体制の評価 |
| COMmmmONS 1.0.0 | 原本 OpenAPI 3.0.4 の入出力検証、全 19 操作の限定条件での成功・拒否 | 全本文要件の適合、接続先との相互運用性 |
| 予約 | 指定乗降場所・単一サービス・合成一般区分・設備指定なし。候補と承認内容を照合 | 自宅/エリア型、複数サービス、実際の利用者区分・支援設備 |
| 決済情報 | 管理者が確認した金額と状態を予約ごとに記録 | 実課金、決済代行事業者との接続、返金処理 |
| 車両位置・遅延 | 明示的に登録した合成観測、取得時刻、有効期限、未取得と遅延なしの区別 | 実車の GPS・運行システム・収集基盤 |

| MCP | 2026-07-28、公式 SDK 2.2.0、ローカル HTTP、6 ツール、共通 Core への委譲 | 外部クライアントと本番認証・権限の接続検証 |
| A2A | wire version 1.0、公式 SDK 1.1.4、Agent Card、Task、再送・再開、共通 Core | 外部エージェントとの本番接続、運用合意 |
| HTTPS・外部認証 | ローカル試験用 TLS と模擬認証提供者を使う認証・署名検証 | 実際の認証提供者、登録クライアント、実鍵、公開ホスト |

COMmmmONS 原本は認証方式・一般的な再送キー・タイムアウト値を指定していません。このローカル環境の委任・承認・再送キーは MDL の安全要件です。国の必須仕様とは呼びません。公式原本内のサンプルサーバー URL も国交省の本番 API として使用しません。

公式本文の「各検索条件は AND」と「ID 指定は他条件より優先」の組合せは優先範囲が明確でなく、追加確認事項です。現コードは既存の AND 絞り込みを維持しています。即時呼出の `requested` を標準の `tentative` に対応づける意味も、確定期限を伴う仮予約との整合確認が残ります。

合成観測・GTFS 出力・模擬認証を実データとして公開しません。GTFS の外部 validator の過去の結果は今回の再実行結果に含めていません。最新の自動テストで示すのは、コード内の国内要件検査と合成フィードの検証です。

バックアップは `scripts/backup_local.py`、状態点検は `scripts/inspect_local_health.py` で実行できます。復旧コピーは認証情報・委任を持ち越さない設計です。これらのローカル試験を、本番の災害復旧保証とは表現しません。
