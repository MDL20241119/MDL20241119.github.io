# 国土交通省原本の出典・利用条件

出典：[国土交通省 COMmmmONS デマンドバスシステム連携API標準仕様書](https://www.mlit.go.jp/commmmons/document/003/)（2026-09-19取得）。

[国土交通省の著作権・利用条件](https://www.mlit.go.jp/link.html)、[別条件の対象一覧](https://www.mlit.go.jp/page/kanbo01_hy_003657.html)、[公共データ利用規約 第1.0版（PDL1.0）](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)を確認した。今回選んだAPI YAMLには個別のlicense・著作権条件の記載を確認せず、対象一覧にもこのAPIの例外指定は見当たらなかった。出典表示・加工の明示を伴って原本と索引を同梱する。

公式ZIPとextracted/API内のYAMLは変更していない。index/ と operation-map.json は原本をもとに本作業で作成した索引・対応案であり、国土交通省の作成物・認定・適合証明ではない。ZIP内のロゴ・第三者コンテンツを別用途へ転載する権利を表明しない。アプリ画面には公式ロゴ・写真を使用していない。

取得日時・バイト数・SHA-256は acquisition.json、API表示用原本とのバイト一致は display-comparison.json に記録。
