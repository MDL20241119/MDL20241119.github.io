# Security and sensitive information

Report suspected leaks or vulnerabilities privately to **info@mobilitydlab.com**.
Include the affected URL, approximate time and reproduction steps using dummy data.
Do not put personal records, credentials, nonpublic operator data, or an exploit payload containing real records into public issues, pull requests or comments. Do not email raw passenger records or working credentials.

The published atlas is a static public demo. It has no application endpoint for uploading passenger files and no user accounts. Local imports, browser storage, exported files and shared URLs still need appropriate handling. See [the visitor information page](https://mobilitydlab.com/oita-mobility/usage.html).

For maintainers, see [PUBLICATION.md](PUBLICATION.md). If a credential is exposed, revoke or rotate it first. Deleting a file or adding an ignore rule does not remove past commits, caches or forks. Use [GitHub's sensitive-data removal procedure](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository) and assess the affected data before restoring service.

This contact route is not a response-time guarantee or a bug-bounty programme.
