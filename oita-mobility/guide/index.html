行って帰れる？

地図で出発地と行き先を選び、用事のあとに戻れるか調べます。

  1. 出発地と行き先

    出発地、行き先の順に地図を押します。場所を文字で探すときは「場所を入力・日時や条件を変える」を開きます。ほかの市町村の行き先も探せます。

  2. 日時と条件

    「日時を変える」で、日付・出られる時刻・用事の開始・滞在時間・戻りたい時刻を設定。「往復を調べる」を押します。必要なときだけ徒歩や乗換の条件を広げます。

  3. 結果の読み方

    「往復」「行き」「帰り」を切り替えて候補を確認します。候補なしと、データ不足で判断できない場合は別です。歩行距離は概算。運賃・運休・施設の営業時間は出発前に確認します。

  4. 鉄道・地域交通

    通常の往復検索はバス。「JRの判定・対応状況」に公開ダイヤで確認した一部の事例と、端末内で使えるGTFSの入口があります。「グリスロ・ふれあい交通」は収録区間の停留所間を別判定。予約条件も確認します。

  5. 片道で探す

    「この場所から行ける施設も見る」は30分・60分以内の片道候補です。往復を保証する表示ではありません。

時間帯別に乗れる場所

「乗れる場所」タブで、乗り場までの距離と、選んだ時間に使える便を別々に見ます。

  1. 場所と時間を選ぶ

    自治体と判定日を選び、朝・昼・夕方・夜または時刻を切り替えます。地図の区域を押すと、その場所の判定理由が分かります。

  2. 地図の色を読む

    凡例で「乗り場が遠い」「近いがこの時間の便が少ない」「データ不足」を区別します。駅が近いだけで列車に乗れるとは判断しません。

  3. 距離の目安

    大分市の計画を参考に、バス停500m・駅800mを初期値に使います。駅は目的に応じて1kmにも切替可。直線距離の目安で、全国一律の基準や市の正式指定ではありません。

  4. 次の行動

    地図の地点から「ここから行って帰れる？」へ進むと、出発地点を引き継げます。「観光地を探す」では地図の観光地点を選んで往復を調べます。

  5. 収録範囲

    JRは大分市内17駅の2026年11月28日の時間帯を確認した範囲です。他の日、すべての鉄道の往復、グリスロ・ふれあい交通を含む全市域の判定を保証しません。

改善を考える

上部の「改善を考える」から「現状分析」が開きます。地域を調べ、対策の候補を絞ります。

  1. 現状分析

    市内全体・佐賀関・富士見が丘と過去の分析をタブで切り替えます。「便の数」「到達できる停留所」「乗降人数」は別の指標です。

  2. 地域の移動の課題

    停留所まで歩ける場所と、通院・買い物を済ませて帰れる場所を、同じ地域でも別々に見ます。実際の必要外出と照らして、何が制約か確認します。

  3. 改善を試す

    現状と同じ条件で、バスの増便・時刻変更を比較します。予約交通などは改善後の見込み・費用を入力して比べる試算で、自動の経路再計算ではありません。

  4. 乗り降り実績

    事業者集計のCSVを読み込み、期間・停留所・便の単位を確認します。ODは実際の出発地・到着地の組が分かるデータで確認。例示CSVは実績ではありません。

  5. 観光客の動き

    観光の来訪・宿泊・消費は集計年と範囲を確認します。観光地への行き方は地図側の「観光地を探す」を使います。

資料・出典と詳しい使い方

画面上部の「全体」から、現在地、マニュアル、データ・出典を確認できます。

  1. データ・出典

    データ・出典で、提供元・取得日・有効期間・収録外の交通を確認します。計算結果は公式計画や当日の運行保証ではありません。

  2. 庁内の議論

    まず同じ判定日・条件で比べ、次に現地と運行事業者に確認します。距離の問題、便数の問題、目的地や受付時間の問題を一緒にしません。

  3. 詳細試算・地域資源

    変更前後の比較、路線・需要・費用の詳細試算、送迎の公表事例は「改善を考える」側から使えます。データの空欄をゼロとして扱いません。

  4. 利用条件・個人情報

    乗降CSVには氏名・連絡先・個人の移動履歴を入れず、集計済みデータを使ってください。必要に応じて利用条件・データの扱いを確認します。
