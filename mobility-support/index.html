WHAT YOU CAN ASK US / 支援内容

申請を見据えた構想から、
現場で動かすところまで。

必要な部分だけでも、全体の伴走でも。
地域の状況・体制・予算に合わせて、
役割と成果物を一緒に決めます。

01 / PLAN

事業構想・実施計画

地域課題、目的、対象者、実施内容と検証方法を整理。

成果物例：事業構想／実施計画／検証計画
02 / CO-CREATE

関係者との調整・チームづくり

行政・企業・大学・住民と対話し、役割と進め方を整える。

成果物例：関係者整理／役割分担／会議・協議設計
03 / LEARN

人材育成・PBLの設計と運営

地域の実課題を題材に、学びと現場の実践をつなぐ。

成果物例：プログラム／フィールドワーク／活動記録
04 / TEST

実証・運行の設計と現場運営

利用場面、乗降場所、利用方法、当日の役割を具体化する。

成果物例：実証計画／運営手順／利用案内
05 / BUILD

データ・アプリを整える

必要な情報を可視化し、運営に必要な仕組みをつくる。

成果物例：データベース／地図／試作アプリ
06 / IMPROVE

結果を測り、次の判断へ

利用、費用、運営負担を整理し、改善と継続条件を考える。

成果物例：実証結果／改善案／継続に向けた論点整理

具体的な支援範囲・体制・費用は個別に相談して決めます。公募の応募主体、審査・採択、実際の運行主体の役割を踏まえて支援します。
