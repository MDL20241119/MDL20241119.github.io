# JMS BIZWEEK 2026 — Unofficial visitor guide

Public, static MDL microsite. Production path: `/jms-bizweek-2026/`.

## Content and provenance
- 41 time slots from official public program information; program verification: 2026-10-07 JST. Venue information reviewed: 2026-10-08 JST.
- 12 forum/stage slots, 28 co-creation slots, 1 CEATEC special session. One reverse-pitch listing at the same time/place is cross-referenced, not double-counted. Untimed pitches are not included.
- Main venue: Makuhari Messe International Exhibition Halls 2 and 3. The CEATEC special session is in a separate building: International Conference Hall 2F, Convention Hall B.
- Venue diagram is an original schematic based on the official map. Hall-side placement is a guide to orientation, not a scale drawing or route. Follow venue signage.
- Official photographs, logos, and map imagery are not redistributed. Direct links lead to original official materials. No rights or endorsement claims.

## Privacy and functionality
- Search, date/category/venue filters, favorites, personal plan, overlap warnings, custom appointments, manually entered travel estimates, and RFC 5545 iCalendar export.
- No account, personal schedule seed, user records, analytics code, backend, or automatic refresh.
- Local storage key `mdl-jms-bizweek-2026-public-v1` is isolated from the owner-private Site. Every new browser starts empty. User input remains in that browser unless the visitor downloads a calendar file.
- Saving a plan is not an attendance reservation. Official registration and program booking are separate.
- GitHub Pages handles normal hosting access logs; external links follow their providers' privacy policies.
