一緒につくるもの

顧客・事業仮説／共創チームと役割／試作・検証計画／次の判断材料

FROM IDEA TO FIRST TEST

考えるだけで終わらせず、
まず試せるところまで。

アイデア、チーム、実験をひとつながりに。
必要に応じて、アプリ開発やデータ分析も組み合わせます。

01 / FIND

顧客と課題を確かめる

誰が、どんな場面で困っているのか。現場の声とデータ、既存の解決策から考える。

成果物例：顧客像／課題仮説／ヒアリング設計
02 / FRAME

事業の仮説をつくる

提供する価値、使う人、支払う人、必要な資源と費用を整理する。

成果物例：事業仮説／検証したい問い／事業構想
03 / CONNECT

共創のチームをつくる

必要な知見や現場を持つ人と対話し、共通の目的と役割を整える。

成果物例：関係者整理／対話の場／役割分担
04 / PROTOTYPE

小さく、触れる形にする

説明資料、サービスの流れ、アプリやデータ画面など、検証に必要な試作をつくる。

成果物例：サービス設計／試作／体験シナリオ
05 / TEST

最初の検証を動かす

どこで、誰と、何を確かめるか。評価の基準を先に決めて実行する。

成果物例：検証計画／実験の運営／結果の記録
06 / DECIDE

次に進む条件を決める

手応え、費用、負担、残った課題を確かめ、続ける・変える・止めるを考える。

成果物例：検証結果／改善案／次の実行計画

支援範囲・体制・費用は、構想と現在の段階を伺って個別に設計します。
