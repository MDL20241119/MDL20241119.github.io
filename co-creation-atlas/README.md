# WORLD CO-CREATION ATLAS

モビリティデザインラボの公開調査レポート。2026年9月27日確認。

https://mobilitydlab.com/co-creation-atlas/

13か国・28事例を8工程で整理。6つの目的別入口、目的・地域・運営主体・工程・全文キーワード検索、一覧／地図の切り替え、ズームできる世界地図、28の詳細ページ、横断比較、実装ガイド、原典リンクを掲載しています。JavaScriptを使わなくてもレポート本文・索引・出典を読めます。

## 更新

`data/cases.json` の事例、`data/media.json` の写真、`data/counterpoints.json` の反証資料を編集し、このリポジトリのルートで実行します。

```sh
python3 co-creation-atlas/build.py
node --check co-creation-atlas/app.js
```

生成した HTML と変更したデータ・資産を同じコミットで反映します。ランタイム依存・API キー・外部地図ライブラリはありません。GitHub Pages で配信します。

## 調査・編集の原則

- 公式の制度・募集要項・契約条件・年報と原著研究を優先。出典に発行主体、公開時点、確認箇所、確認日を保持します。
- 数値の対象年、分母、単位、自己報告と予測の違いを併記。過去の募集を現行募集と表現しません。
- 事実、運営者の自己報告、編集上の分析、未実施の提案を区別します。
- 地域を代表する無作為サンプルではありません。統一的な因果効果・ROI・成功順位は算出しません。
- 地図は概略位置です。ネットワークは運営本部等の代表地点を表示し、個別の訪問先案内に代用しません。
- 非公開の参照資料そのものは掲載していません。

## 写真・動画・地図・フォント

11事例に26点の写真を掲載しています。各写真には、原掲載ページ、作品・撮影者名、時点、利用条件、変更内容を `data/media.json` とページ内に記録しています。写真の権利は各権利者に帰属し、このリポジトリ全体への一括した再利用許諾はありません。再利用時は各素材の条件を確認してください。

Ars Electronica の写真は同施設に関する編集記事での掲載許可に基づき、切り抜き・色変更をせず掲載しています。CERN の写真は施設の活動を伝える情報提供目的で使用しています。CC BY-SA 写真の変更は縮小・表示枠での切り抜きであり、同じライセンスと帰属表示を維持しています。

動画・360°体験22件は公式公開コンテンツへリンク。対応する動画のみ、ユーザーが再生を選んだ後に配信元のプレーヤーを読み込みます。配信元で埋め込みが制限された場合も、元サイトへのリンクで閲覧できます。

地形は Natural Earth 110m land（Public domain）の緯度経度データを等距円筒図法で表示しています。領有権や法的境界を示す地図ではありません。

欧文見出しは Barlow Condensed Black、日本語は Noto Sans JP のローカルサブセットです。各 SIL Open Font License は `assets/*font-license.txt` に同梱。本文に新しい文字を追加した際は、日本語フォントの文字収録範囲も確認してください。未収録文字はシステムフォントへフォールバックします。

## 地図 UI（2026-09-27）

地域と国の選択を一覧と連動。地図の集合表示は拠点数、単独地点は都市名で案内し、拠点名一覧からも選択できます。スマートフォンでは選択情報をダイアログで表示し、地図の移動は専用ボタンで有効にします。地図は代表地点の概略図で、詳細な訪問経路を示すものではありません。

`map-ui.html`、`map.js`、`map.css` が地図の表示・操作を担当。国形状はNatural Earth 110m Admin 0 Countries（Public domain）から変換し、元データのハッシュと出典を `assets/map-source.json` に保持しています。`assets/map-countries.json` は描画用パスです。
