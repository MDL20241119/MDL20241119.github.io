FIRST, THE TAKEAWAY

車が中心。
でも、車だけじゃない。

2022年夏の由布院調査では、自家用車が51％。JRが21％、レンタカーが14％と続きました。到着手段ごとに、まちへ入る場所も、必要な案内も違います。

この特集の読み方
３つの調査を平均したり、一つの円グラフにまとめたりしません。「どこで・いつ・誰に聞いたか」と一緒に読みます。

05

FROM DATA TO A BETTER JOURNEY

「来る」を、
「過ごす」へ。

ここからはMDLの分析・提案です。交通量の観測や施策の効果を確認した結果ではありません。

  1. 01

    来る

    出発地・交通手段・
    到着時刻を記録

  2. 02

    降りる

    駅・駐車場・乗降場の
    集中と待ち時間を確認

  3. 03

    巡る

    歩行・立寄り・荷物の
    困りごとを把握

  4. 04

    戻る

    帰路・乗継ぎ・再乗車の
    安心を確かめる

01 / COUNT

同じ日に、数える。

平日・休日、季節、時間帯をそろえ、駐車場の入出庫、バス台数、乗降人数を把握する。

02 / CONNECT

移動の前後をつなぐ。

出発地・次の目的地、宿泊／日帰り、滞在時間を同じ調査票で聞く。個人を特定しない集計にする。

03 / TEST

小さく試し、比べる。

駐車・乗換え案内や荷物対応を試し、歩きやすさ・待ち時間・店舗への回遊を実測する。
