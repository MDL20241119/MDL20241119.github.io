CASE 73 / ベルギー / ヘント

Ghent Circulation Plan

ヘント・交通循環計画

通過交通を止める変更と、迂回先を含む到達可能性の評価を対にする。

中心部を六つのセクターに分け、自動車でセクター間を移動する時は環状道路を使う交通再編。中心部へのアクセスを全面禁止するのではなく、通過する車と目的地へ向かう車を分ける仕組みである。数年の準備の後、2017年に短期間で通行方向や標識を切り替えた。その後の二段階評価が、歩行・自転車・公共交通の利用と、局所的な問題の両方を確認している。

DESIGN BACKWARDS FROM IMPLEMENTATION

社会実装から逆算して、
何を先に整えているか。

実証の先にある導入・運用・継続から、この事例の設計を読み解きます。原典で確認できる仕組みと、MDLの設計解釈・他地域へ応用するための提案を区別して読んでください。「提案」「未実施」と記す内容は、当地で実施済みの工夫ではありません。仕組みの存在と、全案件で成果が出たことも別に扱います。

01

通過交通の除去から経路を設計する

中心部に目的を持たない交通を課題にしたため、中心部全体のアクセス禁止ではなくセクター間の経路変更が選ばれた。目的地到達を残す構造として読む。

MDLの分析出典 1
02

評価を二度行い反対説明を確認する

第二回評価は経路や行動の情報を追加し、最初の傾向が続くかを確認した。短期の混乱や慣れによる変化を一度だけの測定で固定しない構造となる。

MDLの分析出典 1
03

平均から局所へ戻す

市は交通量の全体的な減少と、増加した道路や時間損失の残る箇所を併記する。均一な効果を仮定しないことが、信号等の調整へつながっている。

MDLの分析出典 1

MORE DETAIL / 運営・根拠・応用

運営の全体像と、学びを深める資料。

費用負担、公表値、応用条件、写真・動画、原典を続けて確認できます。

01どう動かしているのか。

交通量の計測で中心部の通過交通を課題として把握し、交通の抜け道を切る。六地区の間を自動車で移動する場合はR40へ誘導し、公共交通や必要な業務の扱いは区別する。評価では速度・交通量、経路、移動手段、住民の意見等を照合した。自転車や公共交通への移行が報告される一方、一部道路では交通が増え、到達性への評価も居住場所や移動手段で異なる。全員が賛成した政策とも、自動車アクセスがなくなった政策とも扱わない。

  1. 通過と目的地交通を分ける
  2. 通行体系を切り替える
  3. 異なる指標を照合する
  4. 問題の残る箇所を調整する

02誰が負担し、誰が担うか。

市の交通政策として整備・運用。評価の依頼者は市の交通部門。整備、警察等の運用、評価を合わせた総費用と長期維持費は今回未確認。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。

04日本で活かすなら。

設計提案：通過交通の抑制では、境界道路への負担と必要な配送・医療等の到達性を先に評価条件へ入れる。中心部だけの交通減を成功とせず、経路の変化、徒歩・自転車への移行、周辺の遅れを同じ期間で測る。
