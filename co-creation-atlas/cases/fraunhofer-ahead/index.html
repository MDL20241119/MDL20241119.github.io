CASE 27 / ドイツ / ミュンヘンほか

Fraunhofer-Gesellschaft / AHEAD

フラウンホーファー研究機構／AHEAD

受託研究・ライセンス・起業から、出口を選ぶ。

応用研究を産業へ渡す複数の出口を持つ研究機構。企業からの受託収入、公的な競争的資金、基盤資金を組み合わせ、研究の先に契約・知財利用・起業を置く。AHEADはそのうち事業化を育てる仕組みで、顧客課題、チーム、必要な知財を段階的に確かめる。技術の出口と引受先を同時に設計する。

01どう動かしているのか。

研究機構全体は企業契約・ライセンス、公的競争資金、基盤資金の3系統で研究を支える。研究所の技術を既存企業への受託研究やライセンスへ渡すか、チームが起業して市場に出すかを選ぶ。AHEADは4日間のBootcampで顧客・製品・チームの準備度を評価し、個別ロードマップを作る。公式プログラムページではPhase 1は最大6か月・標準5万ユーロで、顧客課題、必要なIP、チームを明確にする。Phase 2はタームシートと市場投入計画をもとに審査し、最大18か月の追加支援と可変額の資金を提供する。研究所と起業家をつなぐ支援者や外部専門家も配置する。研究機構全体の2025年の産業収入は9.66億ユーロであり、約32億ユーロの『契約研究』全体を企業売上と読み替えない。

  1. 技術と顧客課題を照合
  2. 受託・ライセンス・起業の出口を選ぶ
  3. Bootcampと最大6か月の検証
  4. IP・市場投入計画を審査
  5. 必要に応じ最大18か月の事業化支援

02誰が負担し、誰が担うか。

企業は研究契約と知財ライセンスの対価を支払う。連邦・州は基盤資金、公的機関は競争的研究資金を負担。AHEADは研究機構内の事業化支援予算。起業後の投資資金とは分ける。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。

MDL ANALYSIS

04日本で活かすなら。

【分析】日本の共創事業でも、成功を新会社設立だけに限定せず、既存企業への導入、技術のライセンス、事業譲渡、起業を別々の出口として設計する意義がある。研究成果ごとに想定顧客、量産・運用能力の保有者、必要な知財、次の資金提供者を早期に明らかにする。共創拠点は案件を抱え続ける場所ではなく、最も適切な引受先へ渡す機能を持つべきだ。公的資金は短期収益が見えない共通知の形成に、企業資金は個社への導入に充てるという区分を検討できる。ただし短期受託を優先しすぎて長期研究や支払力の弱い社会課題を排除しないよう、公共目的の予算を残す。

05そのまま真似できないこと。

研究機構の大きな収入規模を、小さな共創拠点が同じ仕組みで再現できるとは言えない。長年の研究設備、人材、知財が前提にある。反対仮説は「移転プログラムより研究資産と企業需要が成果を決める」である。AHEADの5万ユーロと最大15万ユーロは段階・記事の対象が異なり、単純な増額と断定できない。設立件数や存続率だけでは売上、利益、公共的便益を確かめられない。

PROPOSAL / 未実施の検証案

06次に、何を確かめるか。

【提案・未実施】技術移転責任者が研究成果5件に対し60日以内に各3社の見込み顧客面談を行い、受託・ライセンス・起業の3出口を比較。2件以上で支払意思、必要なIP、引受先担当者を確認できれば段階支援へ。技術の良さだけで顧客課題が出ない案件は用途転換。追加調査でも支払者・公益負担者がなければ事業化支援を停止。
