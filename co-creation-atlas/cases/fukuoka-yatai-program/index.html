01どう動かしているのか。

屋台基本条例は、市道等占用、道路使用、公園占用等、飲食店営業の各許可を区別し、市と営業者・利用者の責任を定める。施行規則の占用時間は搬入・搬出を含め17時から翌4時で、清掃や周辺環境への配慮も運用条件となる。第6回公募は2026年に6地区23区画を募集し、筆記、書類、面接の審査を予定する。2026年9月時点では選定・開業済みと扱わない。一方、市が4月に取材した第5回公募の営業者は、保管場所の難しさからトラック積載型を採用し、駐車費を抑える工夫や屋外器材の劣化を語る。規制だけでなく準備・撤収を含む運用能力が事業継続の条件となる。

  1. 区画と公募条件を提示
  2. 筆記・書類・面接で候補者を選定
  3. 各許可・器材・仕込み場を整える
  4. 搬入・営業・清掃撤収を日々実施
