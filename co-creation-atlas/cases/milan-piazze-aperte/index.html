CASE 97 / イタリア / ミラノ

Milan Piazze Aperte

ミラノ・ピアッツェ・アペルテ

暫定的な道路の広場化を、市民との管理協定と恒久改修の判断へつなぐ。

塗装や家具を使って道路等を人の居場所へ変え、市民の活動・管理とつなぐ市のプログラム。独自性は色鮮やかな施工そのものより、公募、共同設計、協働協定、評価、恒久化の判断を組み合わせる点にある。2026年には公共・民間・第三セクターの寄付・スポンサーによる改修公募も公開された。

何を先に整えているか。

実証の先にある導入・運用・継続から、この事例の設計を読み解きます。原典で確認できる仕組みと、MDLの設計解釈・他地域へ応用するための提案を区別して読んでください。「提案」「未実施」と記す内容は、当地で実施済みの工夫ではありません。仕組みの存在と、全案件で成果が出たことも別に扱います。

01

三つの出口を分ける

暫定整備、日常管理の協定、恒久改修を別々の到達点として設計すれば、施工後に責任が消えることを防ぎやすい。

協働を資金の代替にしない

選定条件を更新する

MORE DETAIL / 運営・根拠・応用

運営の全体像と、学びを深める資料。

費用負担、公表値、応用条件、写真・動画、原典を続けて確認できます。

01どう動かしているのか。

市民から候補や提案を募り、設計・仮設施工後も協働協定を通じて使い方と維持を調整する。評価・地域反応をもとに恒久整備を検討するが、市の優先順位と予算で判断される。協定締結数、施工数、恒久化数を別々に読む。

  1. 場所と提案を募る
  2. 共同設計と協定をつくる
  3. 暫定的な空間を実装する
  4. 利用と課題を見直す
  5. 恒久化と更新資金へ渡す

02誰が負担し、誰が担うか。

市の公共空間事業と協働相手の活動を組み合わせる。2025年の参加フォーラム支援総額€30,000はイベント用で、全整備費ではない。2026年公募は寄付・スポンサーによる改修資金を募る仕組みで、調達済み総額を意味しない。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。
