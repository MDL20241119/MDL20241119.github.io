DESIGN BACKWARDS FROM IMPLEMENTATION

社会実装から逆算して、
何を先に整えているか。

実証の先にある導入・運用・継続から、この事例の設計を読み解きます。原典で確認できる仕組みと、MDLの設計解釈・他地域へ応用するための提案を区別して読んでください。「提案」「未実施」と記す内容は、当地で実施済みの工夫ではありません。仕組みの存在と、全案件で成果が出たことも別に扱います。

01

実装上の工夫：実証結果を拡大の発注仕様へ戻す

2024年RFPは2021年実証と共有交通・住民調査の知見を背景に置き、候補地の現地調査、設備ごとの費用・維持条件、設置後のマニュアル等を要求する。これは学習から発注への接続を示すが、後続拠点の完成確認とは別である。

試行段階から清掃・修繕・植栽の担当を確保する。設備の仕様書を引き渡すことと、その担当者が継続予算を持つことは別なので、運用費を確認する。

MORE DETAIL / 運営・根拠・応用

運営の全体像と、学びを深める資料。

費用負担、公表値、応用条件、写真・動画、原典を続けて確認できます。

01どう動かしているのか。

既存の交通と公共空間に、場所ごとに異なる部品を追加する。実証では共有交通の利用データと住民調査を分析し、拡大段階の候補選定へつなげた。後続の調達には設備ごとの維持管理・費用の整理を求め、設置するだけで終わらない設計を志向する。

  1. 観察：既存交通と住民の要望を調べる。
  2. 実証：場所に応じた交通・滞在機能を設置。
  3. 評価：交通データと公共空間への関心を確認。
  4. 拡大：後続調達へ反映するが完成とは区別。

02誰が負担し、誰が担うか。

市の調達による設計・設置支援と、各共有交通サービスの運営を組み合わせる。2024年RFPの予算は計画上の上限であり、支出済み総額や年間運営費ではない。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。
