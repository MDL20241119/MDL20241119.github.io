VALUE CREATION / 価値が生まれる仕組み

この事例を、4つの切り口で。

車両、充電、金融、保証の責任を組み替え、全車電動化を運行へつなぐ。 高い初期購入費と電池性能のリスクを、運行会社だけが一括負担する構造から変える。初期の車体・電池分離は取引関係が複雑で、全車リースでは関係を簡素化した。設備所有と運行、充電と保証を接続することが実装の核心である。

MORE DETAIL / 運営・根拠・応用

01どう動かしているのか。

高い初期購入費と電池性能のリスクを、運行会社だけが一括負担する構造から変える。初期の車体・電池分離は取引関係が複雑で、全車リースでは関係を簡素化した。設備所有と運行、充電と保証を接続することが実装の核心である。

  1. 運行要件を設備条件にする
  2. 資産と責任を分ける
  3. 車両と充電を配備する
  4. 初期不具合から契約を見直す
  5. 都市規模へ展開する

02誰が負担し、誰が担うか。

当時の国・地方政府補助、運賃、事業者のリース料・充電料を組み合わせた。2021年研究が示す補助や金利を2026年の現行契約条件としない。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。
