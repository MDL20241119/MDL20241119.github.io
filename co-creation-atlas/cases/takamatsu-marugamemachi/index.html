DESIGN BACKWARDS FROM IMPLEMENTATION

社会実装から逆算して、
何を先に整えているか。

実証の先にある導入・運用・継続から、この事例の設計を読み解きます。原典で確認できる仕組みと、MDLの設計解釈・他地域へ応用するための提案を区別して読んでください。「提案」「未実施」と記す内容は、当地で実施済みの工夫ではありません。仕組みの存在と、全案件で成果が出たことも別に扱います。

01

所有継続の条件から利用権を組み直す

観測された工夫：A街区は地権者の土地継続所有を保つ一般定期借地62年と店舗の売上歩合賃料を組み合わせた。土地を購入する案ではなく、出店可能な利用条件と長期の権利合意から建物・用途へ戻る仕組みである。他街区の契約にそのまま広げない。

MDLの分析出典 1
02

負担と権限を契約へ落とす

移植時は建設と運営の負担を分け、清掃・安全・修繕・撤退時の責任を契約で確かめる。未確認の費用をゼロとして収支を作らない。

MDLの分析出典 1出典 2
03

評価して次の投資を決める

未実施の検証案：運営者と市が街区別入居・売上・維持費を広域の空き店舗率と並べ、周辺からの移転と純増を分けて年度ごとに確認する。 利用と負担が両立すれば継続、片方のみなら運営変更、維持負担が上限を超えれば拡張を停止する。

MORE DETAIL / 運営・根拠・応用

運営の全体像と、学びを深める資料。

費用負担、公表値、応用条件、写真・動画、原典を続けて確認できます。

01どう動かしているのか。

A街区は約3,200㎡の敷地に商業・住宅・コミュニティ用途を導入した。国土交通省資料では一般定期借地期間を62年とし、民間地権者が土地を持ち続け、権利者出資法人等が賃借人となる。店舗の売上歩合賃料は、固定的な土地価格をそのまま出店負担へ転嫁しないための調整として読める。契約満了後の延長は95％の地権者同意を条件に30年を限度とする。高松市の第2期中心市街地計画はより広い区域・多数事業を含み、2017年評価で空き店舗率、休日通行量、人口比率の目標に届かなかった。個別街区の稼働と広域政策の成否を混同しないことが重要である。

  1. 地権者の所有継続と利用再編を調整
  2. 借地・賃料・延長条件を契約化
  3. 商業・住宅等を街区で整備
  4. 街区収支と広域指標を別々に評価

02誰が負担し、誰が担うか。

A街区の事業費（建設費）は約69億円。一般定期借地62年、店舗賃料は売上歩合制。証券化併用と公的再開発制度を用いるが、現在の公私負担内訳・修繕積立は未確認。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。
