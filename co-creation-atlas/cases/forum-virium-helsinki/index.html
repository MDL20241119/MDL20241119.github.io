CASE 03 / フィンランド / ヘルシンキ

Forum Virium Helsinki

Forum Virium Helsinki

届きにくい人の声から、公募を設計する。

ヘルシンキ市の非営利イノベーション会社。行政、企業、研究機関、住民を結び、実生活の場で短期実証を運営する。CommuniCityでは支援が届きにくい住民と課題を定義し、公開募集と共同開発へ進んだ。技術の展示会ではなく、市の課題形成能力を外部資金と現場に接続する機能が核となる。

01どう動かしているのか。

取締役会が年次目標・指標を定め、半年ごとに効果を報告する会社組織で、市内部の意思決定と国際プロジェクトを接続する。Agile pilot programmeは同じ課題に複数案を並走させ、概ね6か月で事業者選定、アイデア具体化、現場試行、評価を行う。CommuniCityでは高齢者施設、障害者サービス、病院等の関係者と住民が課題形成から参加し、3回の公開募集を実施。FVHは地域ニーズ把握、募集、現場との調整、実証伴走を担った。終了後には会議・報告用テンプレートを含むマニュアルを公開。実証から得た知見を市の施策に返す役割と、企業のサービス改善・市場展開を支える役割を併せ持つ。公募、現場調整、評価を一貫して伴走する中間組織である。

  1. 非利用者・支援が届きにくい人と課題を定義
  2. 行政現場の課題として公開募集
  3. 複数の技術・方法を実生活で共同検証
  4. 住民・職員の評価を仕様と市の判断へ返す
  5. 運営手順を公開し、別の都市へ展開

02誰が負担し、誰が担うか。

会社は主に外部案件資金で運営し、公式説明では約3分の2がEU財源。2025年予算は€7.1m。CommuniCity全体のEU助成は€4,999,012.50（全期間・全パートナー合計）。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。

MDL ANALYSIS

04日本で活かすなら。

日本で最初に移植すべきは、市の課題責任者と住民に届く地域組織を、技術事業者の公募より先に組む順序だ。自治体、社会福祉法人、交通事業者などの現場を選び、MDL等の中立的な事務局が参加支援と実証調整を担う。同じ移動課題でも、アプリ、人的案内、運行変更など異なる解決策を比較する。企業の新規売上と、住民の達成できた外出・職員工数・公費を分けて測り、終了前に本導入の予算部門と調達条件を確認する。補助金を獲得する能力だけが成長しないよう、生活改善と継続費用を別の責任者が検証する。以上は本調査の提案。

05そのまま真似できないこと。

101実証を101件の成功や正式調達と読んではいけない。公式報告は一部の採用を示すが、全件の契約継続、費用対効果、利用者別便益の分布は今回の公開確認範囲では追跡できない。会社本体の年度予算、欧州プロジェクトの総予算、ヘルシンキ市域と都市圏の担当件数を混同すると規模感を誤る。外部助成に依存する構造には、資金終了時の引継ぎと市の本予算化という残る難所がある。

PROPOSAL / 未実施の検証案

06次に、何を確かめるか。

提案・未実施：自治体のサービス所管課を判断責任者、実証事務局を測定責任者にし、1地域・6か月で3方式を比較。事前に外出未達成率・職員工数・利用者負担を測定し、終了時に総公費、継続契約の有無、非利用者の改善を公開。便益と継続費用が合意範囲なら導入、利用偏りが残れば設計変更、財源終了後の引受先がなければ展開を止める。
