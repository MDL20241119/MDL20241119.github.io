CASE 40 / オランダ / アムステルダム

De Ceuvel

デ・クーフェル

暫定利用で育てた循環型拠点は、技術だけでなく土地契約の出口まで設計する。

旧造船所で、廃用のハウスボートを陸上の仕事場に転用した循環型の実験・文化拠点。建築家、技術者、事業者と将来の入居者が空間をつくり、仕事、飲食、文化活動を重ねてきた。2026年の運営者資料は、現地利用の期限を2027年1月31日とする。継続している拠点を既に終了扱いしない一方、恒久運営が保証された成功例とも扱わない。

DESIGN BACKWARDS FROM IMPLEMENTATION

社会実装から逆算して、
何を先に整えているか。

実証の先にある導入・運用・継続から、この事例の設計を読み解きます。原典で確認できる仕組みと、MDLの設計解釈・他地域へ応用するための提案を区別して読んでください。「提案」「未実施」と記す内容は、当地で実施済みの工夫ではありません。仕組みの存在と、全案件で成果が出たことも別に扱います。

01

期限から存続条件を読み直す

2027年1月31日という現行期限が、文化活動と土地利用権を別の判断にしている。長年の運営実績は存続の論拠になり得ても、契約延長の決定そのものではない。

MDLの分析出典 1
02

再利用資源と入居者を接続する

船を陸上の仕事場へ変える過程に将来の入居者が参加した。資材提供だけでなく使う主体の改修労力を組み込むことで、空間と利用の受け皿を同時につくったと読める。

MDLの分析出典 1
03

異なる専門を場の維持へ分担する

持続可能性計画、造園、建築、工事管理を専門主体が分担し、協会とカフェにも主体の違いがある。拠点の魅力を一つの運営者の能力として扱わない方が移転条件を把握できる。

MORE DETAIL / 運営・根拠・応用

運営の全体像と、学びを深める資料。

費用負担、公表値、応用条件、写真・動画、原典を続けて確認できます。

01どう動かしているのか。

既存資源の再利用と暫定的な土地利用を組み合わせる。建物を一括新築せず、将来の入居者が船の改修に関わり、遊歩道でつながる仕事場と交流の場を形成した。Metabolicは持続可能性計画の構想・実装・研究、造園側は植生を用いる公園の設計・施工・維持を担当したと公式に記す。技術実験の成果と、カフェ・文化事業による来訪機会は別に評価する。期限後の処分・移転を左右する土地契約は、共創活動が盛んなことだけでは解決しない。

  1. 土地利用の期限を得る
  2. 資材と労力を再編集する
  3. 日常営業と文化を重ねる
  4. 期限後の運営を問い直す

02誰が負担し、誰が担うか。

入居・場所利用、カフェ等の事業を組み合わせる。市の公募による期限付き土地利用が基盤。現行の賃貸条件、補助金比率、移転・撤去費用の負担は未確認。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。
