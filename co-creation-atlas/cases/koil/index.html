MORE DETAIL / 運営・根拠・応用

運営の全体像と、学びを深める資料。

01どう動かしているのか。

入会時に仕事や活動予定を面談し、契約とオリエンテーションへ進む。会員は作業場所と相談・交流の接点を使い、コミュニティマネージャーが支援や街の取組を紹介する。2025年5月末に工房の常駐案内・講習、3Dプリンター、レーザー新規利用を終了。2026年5月には故障によりレーザー利用全体を当面休止すると発表した。拠点全体の営業終了ではない。

  1. 活動目的を面談
  2. 会員契約と利用案内
  3. 相談・交流・外部支援へ接続
  4. 設備と支援の現況を再確認

02誰が負担し、誰が担うか。

会員の月額利用料、会議室等の利用料金を設定。機器保守・更新・事業支援の費用配分、施設の総収支は未確認。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。

MDL ANALYSIS

04日本で活かすなら。

応用では、機械の購入費だけでなく講習、安全管理、保守、故障中の代替経路を運営計画に入れる。名称が続いていても提供機能は変わるため、支援一覧に確認日・利用条件・停止状況を表示する。都市全体の実証実績を一つの工房へ帰属させない。

05そのまま真似できないこと。

案件別の総費用・専任工数、参加しなかった人への影響、全案件の継続率と独立した効果評価は未確認。

PROPOSAL / 未実施の検証案

06次に、何を確かめるか。

運営者が現在提供できる支援と外部代替先を棚卸しし、90日間の未充足相談を記録する。機器利用が少ないなら再購入だけでなく外注紹介との費用を比較する。
