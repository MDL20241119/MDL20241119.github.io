DESIGN BACKWARDS FROM IMPLEMENTATION

社会実装から逆算して、
何を先に整えているか。

実証の先にある導入・運用・継続から、この事例の設計を読み解きます。原典で確認できる仕組みと、MDLの設計解釈・他地域へ応用するための提案を区別して読んでください。「提案」「未実施」と記す内容は、当地で実施済みの工夫ではありません。仕組みの存在と、全案件で成果が出たことも別に扱います。

01

運行を続ける条件から施設負担を分ける

観測された工夫：導入時の公設民営に加え、南北接続では市が軌道整備・車両購入、富山地方鉄道が運行を担った。車両導入からではなく、直通運行という利用者サービスと長期更新責任から整備・運行の契約へ戻る。ただし2006年と2020年の効果を混ぜない。

負担と権限を契約へ落とす

MORE DETAIL / 運営・根拠・応用

運営の全体像と、学びを深める資料。

費用負担、公表値、応用条件、写真・動画、原典を続けて確認できます。

01どう動かしているのか。

富山港線は2006年に低床車両、新停留場、運行本数増等を伴ってLRT化した。市の比較表では2005年から2006年の1日平均利用者が平日2,266人から4,893人、休日1,045人から4,917人へ増えた。利用者アンケートは自動車からの転換を約12％とするが、一時点の自己申告である。2020年の南北接続では、富山市が軌道整備事業者、富山地方鉄道が運送事業者となり直通運転へ移行した。接続と会社合併による運賃統合もサービス変更であり、2006年の効果に後年の変化を混ぜない。軌道の保守更新、公的負担、生活上の移動機会を分けて評価する必要がある。

  1. 既存線の需要と技術・収支を検討
  2. 公共整備と民間運行を分担
  3. 頻度・車両・停留場を更新
  4. 接続後の利用と負担を追跡

02誰が負担し、誰が担うか。

富山港線導入は公設民営の考え方で建設費を公共が負担し、第三セクターが運行。南北接続では市が軌道整備・車両購入、富山地方鉄道が運行。現行の費用分担総額は未確認。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。
