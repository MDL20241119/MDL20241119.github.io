01どう動かしているのか。

会員は交流、イベント主催、メンターによるゼミ、相談窓口、専門家支援を目的別に選ぶ。企業や自治体が課題を発信し、会員の技術・事業案と接続する。Business Match-up!はNTT西日本グループとの事業創出を扱い、館内実証は価値や機能を確かめる機会となる。交流への参加だけで調達・出資が確約されるわけではない。

  1. 問いと事業課題を相談
  2. 企業・自治体と接続
  3. 実証・事業共創を選択
  4. 提供開始と継続を別途確認

02誰が負担し、誰が担うか。

NTT西日本が施設を運営。個別実証の費用分担・総運営費は未確認。出資を伴う選考型プログラムと通常の交流支援は別制度。

制度やプログラムの財源と、各参加企業・地域に発生する費用は同じではありません。公開範囲を超える案件別予算・契約条件は未確認です。

MDL ANALYSIS

04日本で活かすなら。

応用では、自由な交流の窓口と投資・導入の審査を明確に分ける。企業の課題所有者を対話へ招き、実証終了時に追加開発・販売・停止を判断する部署を置く。共創の登録件数だけでなく、検証後に仕様が変わったか、予算が付いたかを追う。

05そのまま真似できないこと。

案件別の総費用・専任工数、参加しなかった人への影響、全案件の継続率と独立した効果評価は未確認。

PROPOSAL / 未実施の検証案
