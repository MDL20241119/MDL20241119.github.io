# 別府の観光と交通を読み解く

公開URL: https://mobilitydlab.com/co-creation-atlas/beppu-mobility/

2026年11月4日（日本時間）確認。公開一次資料から、別府市・大分県・全国の対象範囲、調査年、標本、定義を分けて整理する静的ページです。提言は既存の別府共創提案ページに分離しています。

## 再生成

Python標準ライブラリのみを使用します。このディレクトリで、次の順序で実行してください。

1. `python build_sections.py`
2. `python build_supplement.py`
3. `python build_coverage.py`
4. `python build_page.py`

入力は `downloads` 内のJSONと、同じAtlas内の湯布院の項目一覧です。`build_coverage.py` は宿泊・交通の追補も生成するため、順序を維持してください。`style.css` と `app.js` は直接管理します。

## 比較の制限

- 市の外国人観光客推計は2026年7月に改訂され、2024・2025年が遡及改訂されています。旧値や旧計画目標と直接比較しません。
- 観光庁宿泊調査は2026年から施設規模区分が変わるため、2025年と同一系列にしません。
- 複数回答の県交通手段を構成比にせず、別府の交通手段比率や観光バス到着台数に置き換えません。
- 年間利用、日平均乗車、OD標本、供給量、推計消費、KPI目標はそれぞれ別の指標です。
- 写真の出典・加工・利用条件は本文末尾と `assets/credits.json` を参照してください。

月別CSVと出典付きJSONを公開しています。原典の差替え・推計改訂が生じた場合は、出典URLだけでなく時点と定義を確認して更新してください。
