01

「試験が終わった」と「使い続けられる」を分ける

国土交通省の道路社会実験の説明は、評価後の本格導入、実験継続、導入取りやめという分岐を示しています。実験は、導入を決める前の学習にも使えます。実施件数だけでは、その後の状態は分かりません。

MDLでは、実証の評価を「有効そうか」、移行判断を「誰がどの条件で続けるか」に分けます。試作品が動く、利用者の評価がよい、運営費が払える、担当部署が受け入れる、必要な手続が確認できる、という判断は同時に完了するとは限りません。

根拠：国土交通省 道路局・2026年掲載版

02

成果物だけでなく、運営できる情報を渡す

次の表はMDLが提案する引継ぎ用の整理です。報告書を送ったことを受入完了とせず、受け取る側が「何を判断でき、何が足りないか」を確認します。地域運営に必要な体制と資金を扱う国土交通省の資料を、引継ぎの視点へ置き換えています。

設備、データ、運用手順は、それぞれ持つ人・更新する人・利用を判断する人が違う場合があります。譲渡や利用条件を教材で決めるのではなく、責任者と専門担当へ確認する項目として残します。

引き渡すもの受け取る側が知りたいこと確認する役割
課題と評価誰に、何が、どの条件で変わったか。比較の限界は何か所管・事業責任者、評価担当
運営手順通常日、例外、休止の仕事を誰が担うか運営責任者、現場担当
費用と資金初期費用、経常費用、更新・終了費をどう持つか予算・会計責任者
設備・ソフト・知財何を引き取り、使い、改良できるか資産管理、技術、知財・契約担当
データと記録何を保管・共有・更新し、誰が管理するか情報管理・調査担当
参加者への回答採用・保留・終了を、誰がいつ知らせるか住民対応・事務局

根拠：国土交通省・2008 / 国土交通省・2026 / OECD・2022

03

引受先と判断日を、実証開始時に仮置きする

ここでの工程はMDLの提案です。開始時に引受候補へ相談し、中間時に運営負担と不足資料を確認し、終了前に継続・修正・終了の判断材料をそろえます。自治体の予算、企業の購買、地域団体の意思決定にはそれぞれ時期があるため、必要な手続と締切を担当者へ聞きます。

実証で一緒に活動した事業者が、そのまま本導入の相手になると前提を置かないことも大切です。調達・契約・管理の扱いは、所管の担当へ事実を示して確認します。終了時に条件が整わない場合、誰が設備や問い合わせを持つかを宙に浮かせない設計にします。

根拠：国土交通省・2008

04

他地域へ渡すのは、成功の写真より成立条件

OECDは参加者への返答と、過程の評価・学習共有を扱っています。国土交通省の2026年提言も、地域に応じた目標と評価、結果を踏まえた改善を論点にしています。継続しなかった案件も、何が分かったかを整理する対象です。

MDLでは、実証後の記録を「結果／条件／未確認／次の判断」に分けます。たとえば昼間の平地で得た利用結果を、夜間・坂道・別の管理体制へそのまま移しません。設備を複製する前に、人員、費用、権限、利用者の違いを一つずつ照合します。

終了後に追う指標は、運営の継続だけではありません。便益が続くか、担当者の負担はどう変わるか、参加者へ回答できたかを、引受先が無理なく記録できる数に絞ります。結果がまだない期間は「測定予定」「未実施」と表示します。

根拠：OECD・2022 / 国土交通省・2026

05

仮想演習：3か月の駅前実証を、4か月目へつなぐ

以下はMDLの架空の駅前演習で、実証は行っていません。3か月の休憩場所試験を想定し、1か月目に施設管理者を引受候補とします。2か月目には地域団体が準備・清掃・問い合わせの工数を記録し、会計担当が継続費を再計算する計画です。

3か月目の終了2週間前に、管理者と予算責任者が判断する設定にします。Aは通常運営へ移行、Bは日数を絞って追加検証、Cは既存施設の管理へ統合する案です。現状に戻す案も残し、どの案でも撤去・保管と参加者への連絡担当を決めます。

反対仮説は「設備の価値ではなく、実証期間中だけの手厚い人員配置が利用を支えた」です。引受先が担える通常体制を試験条件に含め、主催者が離れた場合を確かめます。移行後30日と90日に、利用と運営負担を見直す計画までが、この演習の成果物です。

WORKED EXAMPLE / 編集部による記入例

どこまで書けばよいか、例でつかむ。

以下は考え方を示す学習用の記入例です。実案件の実績・予算・合意を示すものではありません。

引受候補と判断権限
施設管理者が運営、所管の予算責任者が継続費を判断する候補。
判断日と必要な手続
終了2週間前に判断。予算・契約・資産の扱いは各担当に先行確認。
判断に必要な証拠
休憩の利用状況、通常体制での工数、月額費用、天候と時間帯の違い。
引き渡す物と情報
椅子、点検・清掃手順、集計記録、問い合わせ窓口。利用条件は担当に確認。
継続・修正・終了の条件
通常運営、日数を絞った検証、既存管理への統合、撤去の4案を比較。
参加者と地域への返答
事務局が終了時に判断理由と未解決の懸念を掲示・個別連絡する。
移行後の確認
引受先が30日・90日後に利用と作業負担を点検。無理があれば運営日を修正。

DECISION / 次に何をするか

進む。変える。いったん止める。

以下はMDLによる判断の手掛かりです。担当者と当事者で確認し、判断した日と理由をシートに残してください。

進める条件

移行する目安：便益と限界を説明でき、受け取る側が運営・費用・資産・情報の扱いを確認し、見直し日を決められる。

戻って、変える条件

追加検証へ変える目安：便益は見込めるが、通常体制での負担や季節差など、導入判断を左右する不確実性が残る。問いと期限を絞って再検証する。

保留・停止する条件

導入を見送る目安：利用者への便益を確認できない、または合理的な修正でも引受先と継続条件が整わない。終了処理と結果の返答を行い、記録を次へ残す。
