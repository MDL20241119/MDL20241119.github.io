01 / 概要

まずは、できることから。

世界の事例を探す。仕組みを比べる。基礎を学ぶ。自分の計画を書く。共創とまちづくりを、実践につなげるためのATLASです。

ATLASを使ってみる →

02 / 探す

気になる事例が、見つかる。

知りたい課題からも、気になる国や地域からも探せます。

  1. 「共創」「まちづくり」「すべてを横断」から入口を選ぶ。
  2. 課題・キーワード・目的・地域で絞り込む。
  3. 「世界地図で探す」に切り替えると、場所から事例を選べます。
事例を探す →世界地図を開く →

03 / 比べる

同じ問いで、違いが見える。

運営・費用・必要な支援を見比べ、自分の計画に取り入れたい点を見つけます。

  1. 「共創」「まちづくり」「領域を横断」から見方を選ぶ。
  2. 気になるカードの「比較に選ぶ」にチェック。
  3. 「選んだ事例だけ表示」で、同じ項目を読み比べる。
事例を比較する →

04 / 読み解く

何をしたか、何が変わったか。

掲載事例を、インプット・価値創造機能・アウトプット・アウトカムの4つの切り口で読めます。

  1. 人・場所・関係・お金など、持ち込んだ資源を知る。
  2. 対話・試作・検証と、そこから生まれたものを読む。
  3. 継続利用や暮らしの変化を、出典・確認時点とあわせて確かめる。
4つの切り口を学ぶ →Garraway Fの事例を読む →

05 / 学ぶ

必要なところから、学べる。

21の教材で、基礎・進め方・記入例を確認。必要な工程を行き来しながら学べます。

  1. 初めてなら、リビングラボ・まちづくり・オープンイノベーションの基礎から。
  2. 課題を捉える、仲間をつくる、試す、事業にする。いまの仕事に合う工程へ。
  3. 体制・費用・日常の運営や、仕事が止まったときの教材も。
教材の入口へ →

06 / 計画する

読んだことを、自分の計画へ。

「実践シート」で、自分の案件を6つの欄に整理します。分かるところから書き始められます。

  1. 課題・指標・仲間・費用・試す方法・継続条件を書き出す。
  2. 入力は同じブラウザに自動保存。文章での保存や印刷もできます。
  3. 別の端末へは「全シートをバックアップ」と「バックアップを読み込む」を使います。
実践シートを開く →
