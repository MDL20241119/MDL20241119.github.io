READING THE EVIDENCE

4つの情報種別、5つの確認状態。

情報の性質

FACT
資料に記された事実。報告主体・自己申告・独立検証を区別します。
CALCULATION
公表値からの計算。入力・式・単位・対象期間を表示します。
ANALYSIS
MDLによる分類・タグ・比較・解釈。
HYPOTHESIS
必要能力や次の対策など、今後検証する仮説。

実施の確認状態

IMPLEMENTED
実施を確認
PLANNED
計画を確認。実施済みとは扱いません。
NOT CONFIRMED
未確認。0・未実施には変換しません。
NOT IMPLEMENTED / NOT APPLICABLE
未実施・対象外が明記された場合に限ります。

情報種別と確認状態は別軸です。「MDL活動集計」は、事業側の報告に基づく数字であることを示します。

ABOUT THE DATA

本サイトは、国・自治体・事業主体等が公開する資料をもとに、Mobility Design Labが独自に整理・構造化したものです。MDL大分の実績は、活動記録・実証結果報告・MDL活動集計に基づき、集計主体と数字の定義を明示しています。

「交通空白の6分類」等の一部の分類・タグ・分析は、公式分類ではなく、本サイト独自の分析フレームワークです。

公開資料で確認できない事項は「未確認」とし、「実施なし」「0」とは扱いません。

事業内容や運行条件は変更される場合があります。各事例の最終確認日および一次資料をご確認ください。
