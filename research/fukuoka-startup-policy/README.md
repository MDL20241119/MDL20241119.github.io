# 都市の成長と暮らし

Public feature within the WORLD CO-CREATION ATLAS's place-making research.

- Feature: https://mobilitydlab.com/research/fukuoka-startup-policy/
- Atlas entrance: https://mobilitydlab.com/co-creation-atlas/#city-growth-feature
- Published edition: 2026-10-11, 37 pages, Fukuoka and ten world cities.

The hub provides five question-led chapters and city-level reading routes.
`read.html` preserves the final 37-page manuscript and its qualifications.
The viewer carries 272 source records and 21 photographic/visual provenance
records; these are records, not counts of independent studies or causal effects.

Page URLs use `read.html#1` through `read.html#37`. The reader supports buttons,
keyboard, horizontal swipes, the contents dialog and browser history. Source
panels retain scope, dates, definitions and limitations. PDF downloads are
provided in portrait and landscape formats. No account, analytics collector or
backend is introduced.

The feature is separate from the Atlas case database. Do not add its 37 pages
to the Atlas's case, country or photograph totals. The Atlas navigation and
feature entrance are produced by `navigation.py` and `city_research.py` within
the Atlas directory. Keep the hub's return link pointed to the place entrance.

Validation from the repository root:

```
node tests/fukuoka-research.test.mjs
python co-creation-atlas/test_atlas.py
python co-creation-atlas/test_experts.py
```

Image rights remain with the original rightsholders. See the feature's source
and photograph disclosures before reuse. The research is MDL's independent
analysis and proposals, not an official municipal plan or an approved project.
