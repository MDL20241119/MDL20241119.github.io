OUR STORY / VALUE CREATIONインプットから、地元の笑顔まで

地元の仲間と挑戦し、 地元の笑顔へ。

地元の企業、大学、学校、団体、生活者。 互いの強みを持ち寄り、一緒に価値をつくる4段階です。

おおいたプラットなど異業種の地元企業との連携を構想し、トヨタカローラ大分が技術やモビリティをつなぎます。大学・学校・生活者も、企画から実践・改善まで一緒に取り組める場を目指します。

  1. 01 / INPUT

    インプット

    地元の企業・大学・学校・団体・生活者が、課題・技術・人材・地域資源を持ち寄る。

    トヨタカローラ大分は、トヨタグループの技術や陸・海・空のモビリティをつなぐ力を持ち寄ります。

    持ち寄る力の例

    地域の課題や生活の経験、企業の技術・仕事、大学・学校の研究・学び。e-Palette、自動運転実証、サービス企画、アプリ開発、データ分析、車両管理・保守整備など。

  2. 02 / CO-CREATION

    価値創造の場で 仲間と一緒に挑戦

    人材育成プログラム・コンソーシアムで、立場を越えた仲間と考え、つくり、試し、改善する。

  3. 03 / OUTPUT

    アウトプット

    具体的なサービス・事業・運営チーム・継続の仕組みを生み出す。

  4. 04 / OUTCOME

DISCUSSION / 県と相談したいこと

仕組みと具体的な実装を、同時に前へ。

県の組織体制をこちらから指定せず、進め方を実務者の皆さまと協議します。

  1. 01 / コンソーシアムへの県の関わり方

    県としての参画・応援、県側の実務窓口、必要な関係部署との接続、2027年1月の正式発足までの進め方。

  2. 02 / 翌年度実装候補4案件の形成
