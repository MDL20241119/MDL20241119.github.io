02 / PROCESS進め方

募集から実証準備へ、
6つのステップ。

全4〜5回の構成を検討。
専門家や地域の仲間と、
同じ自治体の課題に伴走します。

  1. STEP01

    募集

    県から自治体へ案内交通・福祉・観光・まちづくり等へ。

    →
  2. STEP02

    課題

    課題のある自治体を選ぶ課題・参加意向・受入条件を確かめる。

    →
  3. STEP03

    議論

    みんなで課題を考える自治体・企業・学生などが共に学ぶ。

    →
  4. STEP04

    開発

    課題分析・サービス開発必要なサービスと担い手を考える。

    →
  5. STEP05

    分析

    アプリ開発・データ分析技術とデータを生かし、改善へ。

    →
  6. STEP06

    実証準備

    候補フィールドを検討次年度以降の実施条件を整理し、見通しを立てる。

    →

FIELDWORK受入自治体・関係者と相談する選択肢

希望自治体の
現場で確かめる。

希望する自治体と、現地調査の内容・受入条件を相談します。

A

e-Paletteアイデアソン

地域の課題から、車内の使い方を考える。

学生・住民・自治体職員で発想し、事業者・住民と意見交換。

B

自動運転の実証候補地調査

実証を希望する自治体と、適した場所を探す。

現地の課題・ルート・運営の担い手を確認。必要に応じて先行事例も参照。

C

生活アクセス調査

通院・買物の行きにくさを見つける。

住民の声と生活動線を調べ、地域課題マップにまとめる。

D

停車e-Paletteの使い方

移動拠点として必要な機能を考える。

停車車両の配置を試作し、住民・事業者と使いやすさを確認。
