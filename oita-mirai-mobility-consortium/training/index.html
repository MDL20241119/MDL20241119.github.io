2026年度人材育成プログラム案

大分未来モビリティ人材育成プログラム

地域の課題を持ち込み、解決を進める。

企画・開発・実証から、車両管理・整備保守まで一括で。

自治体が抱える移動の課題や、実現したいサービスを出発点に、必要な技術と専門家の支援を組み合わせて取り組む、実践型の課題解決プログラムです。その実践を通じて、地域の人とチームが育ちます。

期間
2026.11→2027.02
課題を持ち込んで相談する ↗候補日を見る ↓

自治体職員・地域事業者・住民・学生などが参加できます。自治体の参加は無料です。

会場候補：Garraway0・参加自治体の現地

困りごとや、実現したいことから。

解決方法や使う技術は、参加してから一緒に具体化します。

  • 移動の不便

    買物・通院・観光など、地域の移動を便利にしたい。

  • e-Palette活用

    トヨタのe-Paletteを使ったサービスを開発したい。

  • 運転手不足

    自動運転で、運転手不足の解消を目指したい。

  • アプリ開発費

    アプリをつくりたいが、開発費が高い。

  • データ活用

    データを分析し、施策やサービスの改善に使いたい。

  • DX・AI活用

    DXやAIを、実際の仕事やサービスに活用したい。

必要な支援を、一括で。

地域の課題に応じて、必要な技術と専門家の支援を組み合わせます。

01

モビリティサービス企画

地域の課題を整理し、誰に、どんなサービスを届けるかを具体化する。

02

e-Paletteを活用したサービス開発

トヨタのe-Paletteを使い、地域に合った移動やサービスを企画・開発する。

03

自動運転実証

運転手不足の解消を目指し、地域での使い方と運営条件を実証で確かめる。

04

アプリ開発・DX・AI活用

サービスの利用・運営や、日々の業務に必要な仕組みをつくる。

05

データ分析・改善

利用状況や現場のデータを分析し、サービスや運営方法を改善する。

06

車両管理・整備保守

使い続けるための車両管理・点検・整備・保守まで、まとめて相談・依頼できる。

企画・開発・分析・車両管理・整備の依頼先を個別に探し、全体をつなぐ負担を減らします。

サービスをつくるところから、使い続けるところまで。必要な支援をまとめて相談・依頼できます。

課題解決を進めながら、人とチームが育つ。

地域別 ↗

一緒に企画を考え、実行する仲間づくりの場です。自治体職員・地域事業者・住民・学生が、専門家の支援を受けながら、実際の課題解決に取り組みます。

  1. 01 / INPUT

    インプット

    トヨタカローラ大分が、トヨタグループの技術やモビリティを大分へ。

    自治体と地域の仲間は、課題・人材・地域資源を持ち寄る。

    持ち寄る力

    トヨタカローラ大分：トヨタグループのモビリティ・技術。e-Palette・自動運転実証・サービス企画・アプリ開発・データ分析・改善・車両管理・保守整備の知見。

    地元の企業・大学・学校・団体・生活者：課題・技術・人材・地域資源。

  2. 02 / CO-CREATION

    価値創造の場づくり

    人材育成プログラムで、必要な技術と専門家の支援を受け、地域の仲間と実践する。

    • 考える
    • つくる
    • 試す
    • 改善する

    2027年1月設立予定のコンソーシアムへ。

  3. 03 / OUTPUT

    アウトプット

    地域で使われ、続けられる形にする。

    • 課題を解決するサービス
    • サービスを担うチーム
    • 運営・維持管理の仕組み
  4. 04 / OUTCOME

    アウトカム

    買物・通院が便利になる。地域の仕事や所得が増える。

    地元が喜ぶ。自分以外の誰かの笑顔。

地域で使われ、続けられるサービスへ。

住民が使いやすいか。運営する人が続けられるか。費用をどう支えるか。車両をどう維持するか。企画から考え、現場で確かめ、データで改善します。

6つのステップ

  1. STEP01

    課題を持ち込む

    困りごとや実現したいサービスを共有し、参加する仲間を募る。

    →
  2. STEP02

    課題を知る

    地域の困りごとと、目指す暮らしを確かめる。

    →
  3. STEP03

    企画を考える

    住民・事業者・専門家と、解決方法を考える。

    →
  4. STEP04

    つくる

    必要なサービスとアプリを形にする。

    →
  5. STEP05

    試して改善する

    利用者の声とデータから、使いやすくする。

    →
  6. STEP06

    実証へつなぐ

    2027年度以降の実証に向け、候補地・担い手・運営方法を整理。費用と役割は事業ごとに決める。

    →

e-Paletteアイデアソン

地域の課題から、車内の使い方を考える。

学生・住民・自治体職員で発想し、事業者・住民と意見交換。

B

自動運転の実証候補地調査

実証を希望する自治体と、適した場所を探す。

現地の課題・ルート・運営の担い手を確認。必要に応じて先行事例も参照。

C

生活アクセス調査
