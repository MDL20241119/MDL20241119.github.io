# 大分コンソーシアム 人材育成プログラム企画案

公開パス: `/oita-mirai-mobility-consortium/training/`

地域の課題を持ち込み、トヨタの技術やモビリティ、専門家の知見を活かし、企画・開発・実証から車両管理・整備保守まで一緒に挑戦する実践型プログラムの企画案です。その実践を通じて、地域の人とチームを育てます。今年度は現地課題・サービス設計・開発・データ分析・改善を進め、翌年度以降のe-Palette・自動運転実証候補地の選定につなぎます。日程・登壇・提供条件は調整前。既存の入口スクリプトと設定を引き継いでいます。

- `index.html`、`training.css`、`training.js`: 本文・レスポンシブ表示・印刷とメニュー
- `schedule-candidates.json`: 研修11候補・FW第1候補と予備
- `speaker-profiles.json`: 講師候補の公式情報・写真出典
- `assets/`: 公式サイトの元画像。表示枠のみCSSで調整し、森田氏はコラージュ左の本人部分を表示

写真出典: [日高氏](https://www.maas.co.jp/company/) / [成田氏](https://muddler.mystrikingly.com/) / [森田氏](https://usagi-kikaku.com/about/) / [宮代氏（Garraway F）](https://garrawayf.com/#lnk03)。写真やプロフィールの掲載は登壇の承諾を示しません。

## 説明と表示確認（2026-10-26）

本文は課題の持込み → 6つのオポチュニティ → インプット・価値創造・アウトプット・アウトカム → 6STEPの順です。自治体職員・地域事業者・住民・学生など、どなたでも参加無料です。プログラムで取り組むサービス開発・アプリ開発・データ分析も無料。個別事業の実証・運行費や役割は別途協議します。候補日・講師候補・2025年度の参考入口は保持しています。

`/tests/oita-consortium-responsive.html` に320/390 CSS pxの人材育成・オポチュニティ・アウトプットの表示枠を追加。公開ページを同じオリジンのiframeでそのまま読み込み、既存の閲覧認証も適用します。実機Safariやネイティブ端末の検査ではありません。
