# 大分コンソーシアム 人材育成プログラム企画案

公開パス: `/oita-mirai-mobility-consortium/training/`

地域の課題を持ち込み、トヨタの技術やモビリティ、専門家の知見を活かし、企画・開発・実証から車両管理・整備保守まで一緒に挑戦する実践型プログラムの企画案です。その実践を通じて、地域の人とチームを育てます。今年度は現地課題・サービス設計・開発・データ分析・改善を進め、翌年度以降のe-Palette・自動運転実証候補地の選定につなぎます。日程・登壇・提供条件は調整前。この人材育成プログラムは、パスワードを入力せず直接閲覧できます。

- `index.html`、`training.css`、`training.js`: 本文・レスポンシブ表示・印刷とメニュー
- `schedule-candidates.json`: 研修11候補・FW第1候補と予備
- `speaker-profiles.json`: 講師候補の公式情報・写真出典
- `assets/`: 公式サイトの元画像。講師候補は日高氏・宮代氏、プログラム設計は植野氏を掲載

写真出典: [日高氏](https://www.maas.co.jp/company/) / [宮代氏（Garraway F）](https://garrawayf.com/#lnk03)。写真やプロフィールの掲載は登壇の承諾を示しません。

## 説明と表示確認（2026-10-26）

本文は課題の持込み → 6つのオポチュニティ → インプット・価値創造・アウトプット・アウトカム → 6STEPの順です。自治体職員・地域事業者・住民・学生など、どなたでも参加無料です。プログラムで取り組むサービス開発・アプリ開発・データ分析も無料。個別事業の実証・運行費や役割は別途協議します。候補日・講師候補・2025年度の参考入口は保持しています。

`/tests/oita-consortium-responsive.html` に320/390 CSS pxの人材育成・オポチュニティ・アウトプットの表示枠を追加。公開ページを同じオリジンのiframeでそのまま読み込みます。人材育成ページはパスワード不要です。実機Safariやネイティブ端末の検査ではありません。

「支援を受ける」説明から、地域の課題解決に一緒に挑める「オポチュニティ」へ統一。`../assets/opportunities.css` はこのプログラムとトップ・構想の6項目のキーワード・数字だけに適用する表示調整です。介助・福祉の支援や行政資料の名称は変更しません。

参加対象と無料の内容を冒頭・申込み付近に明記。6つのステップは、参加者の行動と形にする成果を対にして説明します。2027年度以降の実証を決定・保証する表現は加えません。320/390 CSS pxのステップ表示枠も既存の確認ページに追加しています。

6ステップの見出しは「仲間と課題を議論 → 現地現物調査 → サービスを考える → アプリをつくる → データを分析する → 実装計画をつくる」。参加者の行動と成果もこの流れに対応させています。

人材育成ページだけ、共通のentry CSS・スクリプトの読込みを解除。共通ファイルと他ページの認証は保持しています。停車e-Paletteの使い方はAのアイデアソンへ統合し、現地調査はA〜Cの3項目です。カレンダーは「プログラムのカレンダー」と表示し、候補日と登壇候補の区分を維持します。
