# 大分未来モビリティ人材育成プログラム

公開パス: `/oita-mirai-mobility-consortium/training/`

2026年度の国土交通省採択事業を実施するトヨタカローラ大分が、コンソーシアムの立ち上げと人材育成を並行して進めるプログラムです。2026年11月〜2027年2月に地域の課題から、2027年度以降の実証内容・候補地と実施計画を具体化します。

## ファイルと公開

- `index.html`: 自治体向け本文。既存デザイン・写真を維持し、パスワード不要で閲覧できます。カレンダーは一時非公開です。
- `lecture-20261111.html` / `lecture-editorial.css`: 日高洋祐氏の11月11日14:00〜16:00の講演を大きく訴求する専用ページ。日高氏の登壇・日時は確定。会場・講演内容・進行・申込方法は調整中。既存の公式掲載写真を使用。
- `seminar-promo.css`: 人材育成プログラムのトップページに、日高氏の写真・経歴・確定講演日を掲載する特集セクション。
- `training.css` / `concise.css` / `training.js`: 既存スタイル、メニュー、印刷。
- `municipal.css`: 追加説明・相談導線・印刷の補助スタイル。共通ファイルや他ページに変更を加えません。
- `guide.html` / `program-guide.pdf`: 関係部署に共有する概要ページとA4・2ページのダウンロード用PDF。
- カレンダーのHTMLと `schedule-candidates.json` は公開配信から外しています。復元用データは下記のGit履歴に保持しています。
- `speaker-profiles.json` / `assets/`: 講師プロフィールと既存写真。日高洋祐氏は登壇確定、宮代陽之氏は登壇候補、植野直亮氏は講師・プログラムプロデュースです。

既存GitHub Pagesの`main`ルート配信を使用します。ビルドや外部予約システムは追加していません。Googleフォームへのリンクを上部・写真横・参加案内に置き、フォーム自体は変更しません。

## 内容の判断基準

自治体参加とプログラム内のサービス開発・アプリ開発・データ分析は無料。個別の実証・運行・継続的な車両管理と整備保守の条件や費用は個別協議です。優先検討と実施確約を区別し、今年度の現状調査・試作評価と来年度の実運行による効果検証を区別します。

講演は日高氏・宮代氏を中心に各1回・2回程度を想定。講師カードと講演案内は維持し、月別の候補日カレンダーは一時非公開にしています。6ステップは6回の必須出席を意味せず、参加回数・所要時間は調整中です。
