# 地域・団体別の提案PDF

一覧カードと各詳細ページの上部・末尾から、対応するPDFを直接ダウンロードできます。既存のWebデザイン・カードリンク・閲覧入口は維持しています。

対象は別府市、由布市（湯布院）、日出町、宇佐市（安心院含む）、国東市、臼杵市、大分市、太陽の家の8提案です。

## 2ページ要点版

PDFは各2ページ・A4横向き。IR資料を参考に、1ページ目で地域の課題・サービス・目指す変化を、2ページ目でe-Paletteと将来の自動運転、最初の検証・指標・共創体制・対価の仕組みを示します。企画例・未合意であること、技術検討の条件、写真の出典と利用条件を保持します。詳細・全原典は既存Web本文へリンク・QRで案内します。

- `pdf/<ページ名>-proposal.pdf`: ダウンロード用PDF
- `data/proposal-briefs.json`: Web本文に基づく編集済み要約・写真・原典
- `scripts/build-proposal-pdfs.py`: 共通デザインでの生成処理
- `assets/proposal-downloads.css`: 既存のダウンロード導線のスタイル

## 更新手順

Web本文の変更時は要約JSONも見直し、PDFを再生成して同じ公開変更に含めます。JSONは全文の自動転記ではありません。検証指標は実績ではなく検証案として表記します。数値の実績や関係者との合意を補わないでください。

```bash
python3 -m pip install reportlab Pillow fonttools
python3 scripts/build-proposal-pdfs.py --font-variable /path/to/NotoSansJP-variable.ttf
```

日本語フォントと代替指定方法はスクリプトの冒頭を参照。フォントを小さくして詰め込まず、固定した文字サイズでの描画領域を超えた場合は生成エラーにします。公開前に各PDFが2ページであることを検証し、全ページを画像化して確認してください。
