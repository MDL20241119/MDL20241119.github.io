トップの順序: **Vision → Mission → Value → 立ち上げの背景 → 人・モノ・場 → 既存事業の実践 → 5つの成長テーマ → 金鱗湖 → 8つの活用構想 → 事業創出・価値循環 → 共創拠点 → 参加方法 → 構想説明書 → 生まれたコンテンツ → HOW WE WORK**。運営の基本は最下部に、小さめの見出し・薄いグレー・細い罫線で掲載。
