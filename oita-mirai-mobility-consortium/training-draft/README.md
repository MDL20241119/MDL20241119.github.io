# 2026年度 人材育成プログラム企画たたき台

2026年10月19日版。大分未来モビリティ・コンソーシアムHPへ将来追加するための検討用ページです。

## 配置と公開範囲

- 作業ブランチ内の `oita-mirai-mobility-consortium/training-draft/` にのみ追加。
- `main`、既存ホームページ、ナビゲーション、公開設定、配信ワークフローは変更しません。
- GitHubのリポジトリ自体は公開です。ブランチ内のソースも閲覧可能で、`noindex` はアクセス制御ではありません。
- パスワードや個人予定、参加者名簿、私信、連絡先、非公開会議記録は含めません。

## 内容の位置づけ

- 自治体職員を中心に、交通だけでなく福祉・医療介護・観光・住宅等の課題を扱う4回構成案。
- 仮日程は2026年11月27日、12月18日、2027年1月15日、2月12日。全て金曜日。会場・登壇者との調整前、時間未定（午後案）。
- Garraway0公式サイト掲載の公開カレンダーとの重複なしを2026年10月19日に確認したもの。空きの保証や会場予約ではありません。
- 講師は候補で、登壇承諾・正式所属・担当テーマは未確認です。候補者の氏名を推測で補完しません。
- 税抜450万円（研修350万円、フィールドワーク100万円）は企画予算であり、発注・契約の確定ではありません。予算上は各1式で、原本に回数指定はありません。各4回という拘束や費目の細分を確定しません。
- フィールドワークA〜Dは選択肢。全て実施する計画ではありません。実施内容・対象経費・車両や受入地域・運行・許認可・費用負担を別途確認します。
- 個別実証・社会実装は別事業。対話事業・4案件形成との重複計上を避けます。
- 企画書提出や宿題は必須にしない案。記録・教材・評価の取りまとめ目標は2027年2月26日です。

## 構成

- `index.html`: セマンティックHTML。企画内容と確認事項。
- `draft.css`: 既存HPのピンク・黒罫線を継承したレスポンシブデザイン。印刷用スタイルを含む。
- `draft.js`: 印刷ボタン、モバイルメニュー、印刷時の予算説明展開のみ。データ収集・送信・保存なし。
- 写真は既存HP掲載のGarraway0共創活動写真を参照。研修の実施写真と誤認させない説明を付記。

## ローカル確認

ビルド不要です。リポジトリルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/oita-mirai-mobility-consortium/training-draft/` を開いて確認できます。

JavaScript構文確認: `node --check oita-mirai-mobility-consortium/training-draft/draft.js`
