# 2026年度 人材育成プログラム企画たたき台

2026年10月19日版。大分未来モビリティ・コンソーシアムHPへ将来追加するための検討用ページです。

## 配置と公開範囲

- 作業ブランチ内の `oita-mirai-mobility-consortium/training-draft/` にのみ追加。
- `main`、既存ホームページ、ナビゲーション、公開設定、配信ワークフローは変更しません。
- GitHubのリポジトリ自体は公開です。ブランチ内のソースも閲覧可能で、`noindex` はアクセス制御ではありません。
- パスワードや個人予定、参加者名簿、私信、連絡先、非公開会議記録は含めません。

## 内容の位置づけ

- 自治体職員を中心に、交通だけでなく福祉・医療介護・観光・住宅等の課題を扱う4回構成案。
- 研修は月1回、水曜日または金曜日。関係者と選ぶための候補を、月別カレンダーで比較します。すべて調整前・未予約で、研修は午後案です。
- 11月：11/4（水）、11/27（金）
- 12月：12/9（水）、12/23（水）、12/25（金）
- 1月：1/8（金）、1/20（水）、1/22（金）
- 2月：2/5（金）、2/10（水）、2/12（金）
- 公開カレンダー・開催情報等を参考に整理した候補です。空きの保証や会場予約ではありません。12/9はスマートムーブデー、12/25は年末、1/22は近接イベント準備、2/5は別大マラソン直前の受入れ条件に留意します。
- 講師4名の正式会社名・氏名・現職・経歴を公式情報で確認し、出典付きで掲載。登壇承諾・担当日・講演内容は未確認です。宮代陽之氏の現職は「非常勤フェロー」です。
- 写真の本人確認と転載許諾は別として扱います。写真は全員共通の掲載確認中の枠と、公式プロフィールへのリンクで表示し、写真ファイルは複製・公開していません。
- 冒頭に自治体の参加メリット4点（課題の地図・データ整理、サービス設計、希望に応じた開発・分析支援、庁内・地域の仲間づくり）を掲載。無償・一律の完成アプリ提供・特定成果は確約しません。
- 金額は掲載せず、実施内容・成果物・役割を整理しています。
- 希望する自治体には、アクセシビリティマップ、ライドシェアアプリ、必要データの可視化・分析アプリの開発・提供を研修と組み合わせます。課題把握→現場確認・可視化→サービス設計→アプリ・データ要件→希望自治体への開発・提供→地元の仲間と実装・改善、の6ステップを主軸にします。6回の講座を意味せず、研修4回と現場・個別支援の流れです。勉強会と仲間づくりは各ステップに重ねます。
- 対象自治体・機能・データ・費用条件・開発と提供時期・保守運用は個別調整。運行主体・制度対応・既存交通事業者との連携は別途確認します。全自治体への同一条件での提供や一律の納期を確約しません。
- フィールドワークの仮候補は2027年1月13日（水）、予備は2026年12月23日（水）・2027年1月20日（水）。受入先・会場・参加者との調整前で、予約や実施の確定ではありません。実施後の研修で振り返るため、研修の選択日と前後関係を調整します。
- 12/23・1/20は研修候補とFW予備が重なる選択肢です。同日に研修とFWを両方採用しません。
- フィールドワークA〜Dは選択肢。全て実施する計画ではありません。実施内容・対象経費・車両や受入地域・運行・許認可・費用負担を別途確認します。
- 走行実証・運行サービスの社会実装は別事業。希望自治体向けのツール開発・提供との範囲を整理し、対話事業・4案件形成との重複計上を避けます。
- 企画書提出や宿題は必須にしない案。記録・教材・評価の研修・フィールドワークの取りまとめ目標は2027年2月26日です。個別開発の提供時期は自治体と調整します。

## 構成

- `index.html`: セマンティックHTML。企画内容と確認事項。
- `draft.css`: 既存HPのピンク・黒罫線を継承したレスポンシブデザイン。印刷用スタイルを含む。
- `speaker-profiles.json`: 公式情報で確認した講師候補の氏名・会社・現職・経歴・公開出典。私的資料や写真ファイルは含めません。
- `schedule-candidates.json`: 月別の研修候補とFW候補、選択時の留意点。HTMLには静的カレンダーとして表示し、外部カレンダーを作成・変更しません。
- `draft.js`: 印刷ボタン、モバイルメニュー、印刷時の事業範囲の説明展開のみ。データ収集・送信・保存なし。
- 写真は既存HP掲載のGarraway0共創活動写真を参照。研修の実施写真と誤認させない説明を付記。

## ローカル確認
