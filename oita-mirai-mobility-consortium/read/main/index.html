01何を目指すか

地域の課題を、
続くサービスへ。

地域の課題と企業の技術・サービスを掛け合わせ、具体的なプロジェクトを生み出すコンソーシアムを立ち上げます。

私たちが目指すこと。

Purpose

モビリティを通じて、人と地域の可能性をひらき、大分を元気にする。

Vision

「行きたい」「会いたい」「やってみたい」がかなう。人と地域に、豊かさがめぐる大分へ。

Mission

地域の声と仲間の強みをつなぎ、ともにつくり、試し、地域で続く仕組みへ育てる。

Values

  • 持ち寄る
  • ともにつくる
  • 試して学ぶ
  • 役割を担う
  • 人・地域・自然を大切に。

03誰が運営するか

実務は、
TCO・MDLが担う。

事務局が企画から日常の運営まで担い、県・おおいたプラットの後押しをプロジェクトにつなげます。

発起人は、この5区分。

  • 大分県参画を協議
  • 県内各自治体募集中
  • おおいたプラット参画を協議
  • トヨタカローラ大分参画を協議
  • モビリティデザインラボ参画を協議

発起人構成の提案です。県内各自治体は募集中。自治体の個別名は、参画と掲載の了承を確認してから掲載します。

05参加するメリット・会費・議決権

企画を持ち寄り、
仲間と具体化する。

課題や事業機会を知ることから、企画・連携・プロジェクトへの参加、成果の発信へつなげます。

  1. 地域の課題・事業機会を知る。
  2. 企画を提案し、事務局と具体化する。
  3. 一緒に取り組む自治体・企業・団体とつながる。
  4. e-Palette活用・自動運転実証などの企画検討に参加する。
  5. 採択された活動・成果を発信する。

06どう決め、どう進めるか

決める場は、1つ。
検討から実行までつなぐ。

意思決定は「運営会議」（仮称）に一本化。月1回を基本とし、個別プロジェクトとコンソーシアム全体の事項を扱います。

議題 01個別プロジェクト

サービス開発・活用企画・実証など

議題 02全体の事項

全体方針・規約・会員制度・共通予算など

  1. 01

    アイデア・案件・議題を登録

    口頭でも資料でも提案できます。枚数・様式は指定しません。

  2. 02

    運営会議で検討開始を承認

    個別プロジェクトでは「採択」。具体化を始める判断です。

  3. 03

    事務局と関係者で具体化

    TCO・MDLが関係者と、参加者・責任者・期間・内容・費用・必要な条件を整えます。

  4. 04

    同じ運営会議で最終決定

    個別プロジェクトでは「認定」。条件が整った実施計画を判断します。

  5. 05

    実行し、結果を報告・発信

    必要な移動、地域の売上・仕事、サービスの継続性を確かめ、次の改善につなげます。

採択後から「検討中のプロジェクト」として発信できます。

全体の事項も同じ会議体・同じ流れで検討し、決定事項は事務局が記録します。

個別案件の実行・契約・費用負担は、その案件の参加企業・団体が担います。認定は、各団体の契約・支出承認、行政の許可、安全性の保証を代替しません。

発信する内容・名称の使用は事務局と確認し、機密情報は関係者に限定します。

07どう運営費を賄うか・今回相談したいこと

運営を支え、
立ち上げを一緒に進める。

企画・調整・運営を無償奉仕にせず、事務局が継続して動ける予算を組みます。

初年度は、TCOの持ち出しを基本に協議

会費だけでは賄えない想定です。TCOの具体的な負担額・上限は未決で、支出承認済みではありません。

不足分と将来の負担軽減に向け、会費・協賛・活用可能な補助事業などの財源の確保を進めます。

共通運営の会計企画・調整・事務局運営

共通運営の契約・口座・会計はMDLが通常事業と区分して管理し、運営会議へ報告

個別プロジェクトの会計開発・実証・運行など

案件の参加企業・団体が管理

設立準備で詰める事項：体制・発起人の了承、無料対象、定足数・可決条件、会費の年度・月割り、TCOの負担額・上限。
